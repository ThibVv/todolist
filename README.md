# 📌 **ToDoList**

## 📝 Description

Todolist est une application Flutter permettant de gérer ses tâches de manière simple et efficace. Elle permet d'ajouter, visualiser et suivre l'état des tâches avec un système de statuts (à faire, en cours, terminé).


## 📩 Auteur

- [@ThibVv](https://github.com/ThibVv/todolist)


## 🚀 Fonctionnalitées

- 🟡 Ajouter une nouvelle tâche
- 🟠 Mettre une tâche en cours
- ✅ Marquer une tâche comme terminée
- 📋 Affichage dynamique des tâches sous forme de liste
- 🎨 Interface basée sur Material Design


## 📚 Technologies utilisées 

Flutter (Dart)
